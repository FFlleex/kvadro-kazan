# КВАДРО

Адаптивный каталог квартир для долгосрочной аренды в Казани. Портфолио-проект с демонстрационными объявлениями и сгенерированными фотографиями.

- [Открыть сайт](https://fflleex.github.io/kvadro-kazan/)
- Фильтры по району, комнатам и бюджету. Выбор сохраняется в адресной строке и при возврате с карточки.
- Отдельная страница объекта с галереей, стоимостью и условиями аренды.

## Локальный запуск

В корне репозитория выполните `python3 -m http.server 8000` и откройте `http://localhost:8000/`. Сайт использует HTML, CSS и JavaScript-модули. Сборка и установка зависимостей не требуются.

Для GitHub Pages используется ветка `main` и корень репозитория.
